# Get started

> [!NOTE]
> This project uses the [Bun](https://bun.sh) runtime.\
> If you'd rather use a different runtime see [makefile](./makefile), section `update`.

Update dependencies

```bash
make update
```

Then start the server

```bash
make start
```

or build it

```bash
make build
```

> [!NOTE]
> The `ui` directory is not embedded into the final executable.
